🎮 Rock Paper Scissors Game (C++)

A console-based implementation of the classic Rock-Paper-Scissors game using C++. This project demonstrates fundamental programming concepts such as control flow, functions, enums, and basic user interaction.

🚀 Features

Play between 1 to 10 rounds

Randomized computer moves

Clear round-by-round results

Final game statistics (wins, losses, draws)

Replay option after each game

🧠 Concepts Used

Enumerations (enum)

Structures (struct)

Functions and modular design

Random number generation

Input validation

▶️ How to Run

Compile the code using any C++ compiler:

g++ main.cpp -o game

Run the executable:

./game
📌 Gameplay

Choose:

1 → Stone

2 → Paper

3 → Scissors

The computer selects randomly

The winner is decided based on standard rules

📊 Example Output
Round [1]:
Player choose: Stone
Computer choose: Paper
Result: Lose
