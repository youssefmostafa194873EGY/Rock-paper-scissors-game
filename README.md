Rock Paper Scissors Game (C++)

A simple console-based Rock-Paper-Scissors game written in C++. The player competes against the computer over multiple rounds (1–10). Each round randomly generates the computer’s choice, compares it with the player’s input, and displays the result. At the end of the game, a summary shows total wins, losses, and draws, along with the final winner.

Features:

Interactive user input

Randomized computer moves

Round-by-round results display

Final game statistics (wins, losses, draws)

Option to replay the game
